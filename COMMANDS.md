# Commands Used

This file contains the Linux commands used during the SSH authentication log analysis.

---

## Display Network Information

```bash
ip a
```

Displays the network interfaces and IP addresses.

---

## Check SSH Service Status

```bash
sudo systemctl status ssh
```

Verifies that the SSH service is running.

---

## Manual SSH Login Attempt

```bash
ssh admin@192.168.150.129
```

Attempts SSH login using an invalid username.

---

```bash
ssh barakuser@192.168.150.129
```

Attempts SSH login using an existing account.

---

## Password Testing (Lab Environment)

```bash
hydra -l IT-support -P passwords.txt ssh://192.168.150.129
```

Used to simulate password authentication attempts in a controlled lab environment.

---

## View Authentication Logs

```bash
sudo grep "Failed password" /var/log/auth.log
```

Displays failed SSH authentication events.

---

```bash
sudo grep "Accepted password" /var/log/auth.log
```

Displays successful SSH authentication events.

---

```bash
sudo grep -E "Failed password|Accepted password" /var/log/auth.log
```

Displays both failed and successful authentication events.

---

## View SSH Service Logs

```bash
sudo journalctl -u ssh
```

Displays logs generated by the SSH service.

---

## Search Invalid User Attempts

```bash
sudo grep "Invalid user" /var/log/auth.log
```

Displays login attempts using non-existent usernames.
